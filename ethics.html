Copyright & Asset Licensing

Building a website isn’t just about making it look good — it’s about making it responsibly. By respecting copyright, protecting user privacy, and ensuring accessibility for everyone, I’m practicing good digital citizenship. These principles are just as important as the code itself.

🔒

Privacy & Data Ethics

This static website does not intentionally collect unnecessary personal information. It does not include tracking cookies or analytics.

The contact form is only a demonstration and does not send information to a server in this version.

♿

Accessibility & Inclusivity

Images include descriptive alternative text so screen-reader users can understand their purpose.

Example 1: “Profile picture of Your Name.”

Example 2: “Student working on a web development project.”

🛡️

Security

When deployed, this website should be accessed through HTTPS. The project does not store passwords, payment information, or other sensitive data.

Ethics Reflection

Ethical web development means thinking about the people affected by a website. Developers should respect copyright, protect privacy, provide accessible content, and avoid exposing sensitive information. Secure hosting and responsible code sharing also help reduce unnecessary risks.
